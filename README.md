Profi Service — CRM для сети сервисных центров
Внутренняя система управления сервисным центром (CRM) для работы с заявками, клиентами, устройствами, складом и финансами.
Разработана и адаптирована специально для сети сервисных центров «Profi Service» (г. Ульяновск).

🌐 Адреса в продакшене
CRM (админка): https://crm.profi-service73.ru

Сайт-визитка: https://profi-service73.ru

🚀 Ключевые особенности и доработки
Модуль филиалов (Точки):

В базе создана таблица branches («Новый город», «Верхняя»).

При входе пользователь обязан выбрать точку. Админ может переключать филиалы в шапке сайта.

Мастера видят заявки ТОЛЬКО своего филиала.

В шаблоны печати подставляется логотип, адрес и телефон конкретного филиала.

Полноценный UI для управления филиалами (добавление, редактирование, загрузка логотипов) в настройках.

Безопасность:

Сессия живет ровно 10 часов (idle timeout). Галочка «Запомнить меня» удалена.

Мастера без прав на финансы редиректятся с главного дашборда на список заявок.

Вырезаны все внешние ссылки на сторонние сайты (значок «глобус» в navbar).

Печать и брендинг:

Заменен бренд на «Profi Service».

Исправлен баг с исчезновением логотипа при печати (добавлено ожидание загрузки картинок через JS).

Сжаты логотипы для быстрой загрузки (с 237 КБ до 41 КБ).

Цветные иконки в меню, кастомный favicon.

Сайт-визитка:

Тёплая оранжевая палитра, адаптивная мобильная версия.

Плавающая панель звонка с выбором точки.

Интеграция Яндекс.Карт, отзывов и награды «Хорошее место».

🛠 Стек технологий
Backend: Python 3.12, Flask, Gunicorn

База данных: PostgreSQL 16

Frontend: Jinja2, Bootstrap 5, AdminLTE, DataTables

Инфраструктура: Ubuntu 24.04 LTS, Nginx, Let's Encrypt (SSL), UFW, Fail2ban

📦 Установка и развертывание
Требования
Ubuntu 24.04 LTS (чистый сервер)

Доступ под root

Быстрый старт (с нуля)
Репозиторий полностью готов к развертыванию одной командой:

bash
apt update && apt upgrade -y && apt install -y git curl && \
git clone https://github.com/razlock/ProService.git /root/Nika-Service-CRM && \
cd /root/Nika-Service-CRM && chmod +x scripts/*.sh && \
./scripts/linux_setup.sh --with-nginx --harden
Обновление существующей установки
bash
cd /root/Nika-Service-CRM
git pull origin main
./venv/bin/pip install -r requirements.txt
./venv/bin/python scripts/run_migrations.py
systemctl restart nikacrm
⚙️ Основные пути на сервере
Проект: /root/Nika-Service-CRM

Настройки окружения: /root/Nika-Service-CRM/.env

Логотипы (статика): /var/www/nikacrm/images/

Бэкапы БД: /root/backups/ (автоматически каждую ночь в 3:00)

🗄 Резервное копирование
Настроен автоматический бэкап базы данных через cron.
Скрипт: /root/backup_db.sh. Хранит архивы за последние 14 дней.
Все ключи безопасности (пароль БД и SECRET_KEY) сгенерированы уникально для этого сервера.
