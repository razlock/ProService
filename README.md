# Profi Service CRM

**Кастомная версия CRM для сервисного центра Profi Service (г. Ульяновск).**

Проект основан на open-source решении [Nika Service CRM](https://github.com/nika-sc/Nika-Service-CRM), но значительно переработан под нужды двух филиалов: «Новый город» и «Верхняя терраса».

Репозиторий проекта: `git@github.com:razlock/ProService.git`

---

## 🌟 Наши ключевые доработки

В эту версию добавлен ряд критически важных функций и исправлений, которых нет в оригинале:

1. **Мультифилиальность (Филиалы):**
   - Разделение заявок, сотрудников и шаблонов печати по точкам (`branch_id`).
   - Обязательный выбор филиала на странице входа.
   - Переключатель филиала в шапке для администратора.
   - Умная фильтрация: мастера видят только заявки своего филиала, админ — все.
   - **UI управления филиалами:** создание, редактирование адресов, телефонов, цветов и загрузка уникальных логотипов прямо из настроек (доступно только админу).

2. **Печать под каждый филиал:**
   - Поддержка отдельных шаблонов печати для каждой точки (включая уникальный логотип и реквизиты).
   - Единый логотип по умолчанию (`logo_print.png`), если у филиала не загружен свой.
   - Исправлен баг с зависающим уведомлением «Подготовка к печати» на квитанциях приема.

3. **Безопасность и права (RBAC):**
   - Мастера и другие сотрудники без прав на финансы **не видят** сводный финансовый дашборд (автоматический редирект на заявки).
   - **Сессия ограничена 10 часами** (idle timeout). Убрана галочка «Запомнить меня», которая создавала 14-дневные куки. Если сотрудник ушел домой, не выйдя из системы, ночью его сессия умрет.
   - Система прав настроена в соответствии с ролями.

4. **Брендинг и UI:**
   - Везде заменено «Nika CRM» на «Profi Service».
   - Страница входа оформлена в тёплой фирменной палитре (оранжевый/кремовый).
   - Цветные иконки в меню настроек для быстрой навигации.

## 🚀 Установка (Ubuntu 24.04 LTS)

Проект полностью готов к развертыванию одной командой на чистом сервере (VPS).
Минимальные требования: **2 ГБ RAM**, 15 ГБ SSD.

Подключитесь к серверу по SSH под `root` и выполните:

```bash
apt update && apt upgrade -y && apt install -y git curl && \
git clone https://github.com/razlock/ProService.git /root/Nika-Service-CRM && \
cd /root/Nika-Service-CRM && \
chmod +x scripts/*.sh && \
./scripts/linux_setup.sh --with-nginx --harden
